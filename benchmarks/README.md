# Asset-Maker Prompt Benchmarks

A curated 20-prompt stress-test suite adapted from `awesome-opus5-5-videos` covering multi-part hero packages (`3d_hero_package`), full biome scenes (`3d_scene`), 2D sprites, VFX flipbooks, and SFX.

List benchmarks via CLI:

```sh
python -m asset_pipeline benchmarks
python -m asset_pipeline benchmarks --template 3d_hero_package
```
