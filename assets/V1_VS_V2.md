## Reading these numbers honestly

- `ground_darkening` is a luminance ratio, so it is confounded by palette: v1's very dark plinth already scores low. It only proves AO is *present* (the validator threshold is 0.85); it is not a v1-vs-v2 quality score.
- `components` for flipbooks counts every spark and puff, so it is not a quality signal there. Use the contact sheet and `validate_animation`.
- The decisive checks are visual: `preview.png` per asset, and `python -m asset_pipeline audit assets/<name>`.
