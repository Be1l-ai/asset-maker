## 3. Key Failure Modes Caught by `asset_pipeline/audit.py`

See [`vault/pitfalls/procedural_failure_modes.md`](vault/pitfalls/procedural_failure_modes.md) for full details:
1. **`aggdraw` Alpha=0 Erase Trap**: Drawing with `Brush((0, 0, 0), opacity=0)` is a no-op under source-over compositing. Construct shapes with boolean/float masks (`ellipse_mask`, `polygon_mask`, `fillet_mask`) and composite via `over()`.
2. **Dead Imports Posing as Vault Usage**: Importing a helper from `asset_pipeline` without calling it is flagged as an error by `python -m asset_pipeline audit`.
3. **Destructive Vertex Gradient AO**: `bake_vertex_gradient_ao` overwrites all face colors with a two-color ramp. Multi-material props should use multiplicative `bake_ground_ao` and `MeshBuilder.lathe(..., subdivide=3)`.
4. **Non-Periodic Cellular Seams**: Always pass `periodic=True` to `worley_noise` and `tileable=True` to `heightmap_to_normal_map` on repeating tiles, verified via `AssetValidator.validate_seamless`.
5. **Per-Frame RNG Jitter in Flipbooks**: Pre-roll particle tables outside the frame callback; `AssetValidator.validate_animation` catches static frames and single-frame pop spikes.
